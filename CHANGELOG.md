# Changelog

All notable changes to Study Planner are listed here. Versions follow
[Semantic Versioning](https://semver.org).

## [1.0.0] - 2026-10-13

First public release.

### Highlights

- Set up any semester: courses, labs, class times, exams and projects
- Today view with one-tap Done, Partial and Missed, plus a sleep and focus check-in
- Replan a disrupted day or week, with every change shown for confirmation first
- Timed practice sets, an error log and spaced retests
- Weekly progress: completion, accuracy and a short review
- Optional study reminders
- Backup and restore to a JSON file
- No account, no internet use, no tracking: all data stays on your phone
