# Security policy

## Reporting a vulnerability

Please do not put vulnerability details in a public issue, pull request or discussion.

- If this repository shows **Security > Report a vulnerability**, use that form. It is
  private between you and the maintainer.
- If the form is not shown, open an issue titled "Security contact request" with no
  technical details. The maintainer will reply with a private way to send the report.

Include the affected version or commit, steps to reproduce, and the impact you expect.
You should get a first response within 14 days.

## Scope

The app is offline and stores data only on the device. Reports about the following are
especially welcome:

- reading or changing the app's local database from another app
- importing a crafted backup file
- the app making a network request or leaking data
- Android permissions or exported components

## Supported versions

Only the latest release receives fixes.
